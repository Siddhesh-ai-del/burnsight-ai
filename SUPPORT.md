# Support

## Where to get help

- **Questions and discussion:** open a GitHub Discussion or a GitHub issue using the feature request template.
- **Bug reports:** use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.yml).
- **Security concerns:** follow [SECURITY.md](SECURITY.md) and report privately.

## Service level

There is **no SLA at this stage**. BurnSight is pre-release software maintained by a small team; responses are best effort.

## Documentation

The documentation index is [docs/README.md](docs/README.md). Sections marked as planned have not been written yet — check the repository's Project status table in [README.md](README.md) for what currently exists.
